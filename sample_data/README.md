# Sample Data

The Splunk investigation was performed using simulated/educational SSH authentication data.

The raw dataset file is not included in this repository because the source data file was not supplied with the GitHub package.

The SPL queries reference:

```text
source="ssh_logs_new.json"
host="Sanath"
sourcetype="_json"
```

If the dataset is later added, place it in this directory and document the ingestion configuration used in Splunk.
